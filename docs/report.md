## 引言

过去这段顾问周期,核心要回答的是一个产业级命题:

> **"在 AI 替代传统搜索成为流量入口的临界点上,我们公司应该在 AI 产业里站到哪一层、用什么产品形态去站。"**

这份报告不展开技术细节,也不堆业务数字,只围绕三件事:**已经站住的位置(进展)、为此付出的判断代价(难点)、下一步要继续往上走的方向(产品方向)**。

---

## 一、进展(只说成果)

以下都是**已经存在、已经在跑、已经形成对外能力**的成果。

### 1. 产品矩阵已成型:从单点工具升级为"AI 营销度量与干预"全栈

公司从一个单体 CLI 工具,演化为覆盖**诊断 / 测量 / 指标 / 情报**四层的产品矩阵,五条能力线各自独立可售:

| 能力线 | 产品定位 | 当前状态 |
|---|---|---|
| **GEO 体检** | 诊断层 — 网站 AI 友好度评分 | 25 维体系成型,0–100 AI Visibility Score + A–F 等级,中英双语,可生成可视化报告与修复包,有免费 + 付费两档形态 |
| **AI 引擎可见性** | 测量层 — 品牌在 AI 中如何被表达 | 国内 6 引擎(豆包 / 通义 / DeepSeek / 文心 / 元宝 / 智谱)+ 海外 5 引擎(ChatGPT / Claude / Gemini / Copilot / Grok / Perplexity)双轨覆盖,可实测同一品牌在不同 AI 中的差异 |
| **AI 遥测 SAIV** | 指标层 — 把 AI 可见性变成 KPI | 四维指标体系上线:**声量份额 / 竞品引用差 / 命中位置 / 优选率**,日度自动跟踪,行业内尚无对标 |
| **舆情监测** | 情报层 — 跨平台舆情闭环 | 全链路打通:多源抓取 → LLM 结构化分析(立场 / 意图 / 真实性 / 情感)→ 日度简报 → 三档响应草稿;多账户 / 多品牌隔离 |
| **SaaS 化能力** | 商业化基座 | 前端检测主流程 + Dashboard 后台,账号体系、多支付通道、会员分级与配额、中英国际化全部就位 |

### 2. 在赛道里建立了「AI 可见性」的语言体系

> **核心成果:SAIV 指标族(声量份额 + 竞品引用差 + 命中位置 + 优选率)已经是公司对外可用的产业话语。**

这条不是产品,是**资产**。SEO 时代有"关键词排名 / 自然流量 / 域名权重"这套被全行业接受的语言;AI 时代尚未形成。公司已经率先把"AI 可见性"拆解成一组可量化、可比较、可日报的指标,这意味着我们可以在客户面前讲一套**只有我们能讲清楚**的故事。

### 3. 形成了「国内 / 海外」双轨业务能力

| 维度 | 国内 | 海外 |
|---|---|---|
| AI 引擎覆盖 | 6 个国产引擎 | 5 个海外主流引擎 |
| 接入方式 | 浏览器自动化(Cookie 登录) | 官方 API |
| 支付通道 | 微信 / Moltspay 国内通道 | Stripe |
| 内容生态 | 中文 SEO / 中文 AI 引擎 / 中文舆情源 | 英文 SEO / 海外 AI 引擎 |

这意味着公司可以**同时面向中国品牌出海与海外品牌进入中国**两个客群,不必二选一。

### 4. 产品形态已从"工具"过渡到"可订阅 SaaS + 报告产品"

体检结果 / SAIV 看板 / 舆情简报均已经从"跑一次给一份"变成"持续订阅、自动日报、可干预",具备**月费 / 年费**的售卖形态,而不再是一次性服务。

### 5. 行业站位

在 AI 营销 / GEO / AI 可见性这个赛道里,公司已经从"做工具的"前进到具备以下三项的厂商:**(a)有完整产品矩阵**,**(b)有自有指标体系(SAIV)**,**(c)有双轨业务能力**。这三项中任何一项,赛道里同时具备的玩家都不多。

## 二、难点

这一节不写技术挑战。技术挑战是执行问题,可以靠投入解决;**这里写的是顾问期内必须做的产业级 / 战略级 / 产品形态级判断**,这些判断如果当时做错,产品矩阵不会是今天的样子。

### 难点一:AI 引擎本身是不稳定的度量对象

我们要度量的对象——AI 引擎——每个月都在变:模型迭代、答案漂移、反爬升级、生态封闭。这意味着传统"基准化测试"思路不成立:**今天测的"AI 怎么说你"和昨天不直接可比**。

* **判断**:不要追求绝对值,要做**相对值 + 趋势值 + 与竞品的差值**。
* **落地**:SAIV 的"竞品引用差""命中位置"等指标本质上是相对量,这让指标体系对模型漂移具备天然鲁棒性,不需要每次模型升级就重做。
* **回看**:这条判断决定了 SAIV 至今仍然有效,而如果当初做成绝对评分体系,今天已经被模型迭代洗掉了一轮。

### 难点二:「AI 可见性」是一个尚无标准的赛道,既要造产品也要造定义

客户认知还停留在 SEO 时代。"AI 怎么提我"这个问题大多数品牌甚至没意识到要问;意识到要问的也不知道该用什么指标去衡量。我们事实上是在**一边做产品、一边定义客户的问题、一边塑造行业语言**。

* **判断**:先做工具占住"诊断 / 测量"的具体场景,用产品反向教育市场;同时用 SAIV 等指标抢"语言权",为后续平台化与标准化预留路径。
* **代价**:早期客户教育成本高、销售周期长——这是必然的,不应被解读为产品力不足。
* **回看**:这条判断让我们成了少数几家**自带指标体系**的玩家,而不只是一个"AI 时代的 SEO 工具"。

### 难点三:海外浏览器自动化路线的战略性放弃

最初的产品判断是国内 / 海外都走浏览器自动化(便宜、可控、覆盖广)。但 Cloudflare Turnstile 等反爬体系在 2026 年初已经在产业层面把这条路堵死,海外引擎几乎无法在服务器端通过验证。

* **判断**:**主动止损**,海外侧切换为 API 路线,接受更高的单次调用成本,但换取稳定性与可扩展性。
* **落地**:海外引擎全面 API 化,国内引擎保留浏览器自动化(国内反爬态势更温和)。
* **回看**:这条判断如果晚做 3 个月,海外产品线会持续无法稳定交付。**主动承认一条路走不通,比执着继续投入更有价值**——这是顾问视角区别于团队视角的关键。

### 难点四:产品形态的根本性选择 — 工具 vs 平台 vs 数据资产 vs 标准制定者

AI 产业当前阶段,谁都说不清"未来三年这个赛道会沉淀出几家平台公司、几家工具公司、几家数据公司"。我们必须**在产品形态尚未被产业定型之前,提前下注**。

* **当前判断**:**短期工具,中期平台,长期标准**。
  * 短期(0–6 个月):工具占场景,先把现金流跑起来
  * 中期(6–18 个月):用 SAIV 数据 + 多客户 + 行业看板做平台化
  * 长期(18 个月+):推动 SAIV 或衍生指标成为行业通用 KPI,占住"裁判"位置
* **回看**:这条判断决定了所有产品线的优先级排序。今天产品矩阵的形态,本质是这条判断的具象化。

### 难点五:双轨业务的根本性差异

国内和海外不只是"翻译一下界面"的关系,而是**两个不同的客户群、不同的引擎生态、不同的反爬环境、不同的支付与合规体系、不同的销售路径**。

* **判断**:不要把双轨当作"一个产品的两个语言版本",要当作**两个独立产品共享同一套基础设施**。
* **代价**:产品矩阵长期内会保持两条独立线,资源会比单轨更紧。
* **回看**:这条判断避免了"为了统一而牺牲任何一边"的常见陷阱。

## 三、进一步的产品方向

下面五个方向回答的不是"我们想做什么",而是**"AI 产业接下来 6–12 个月会发生什么、我们应该相应站到哪一层"**。

### 方向一:从「度量」延伸到「干预」(主线)

* **产业判断**:客户对"AI 怎么提我"的认知正在从好奇变成焦虑。一旦焦虑形成,他们要的不是仪表盘,**是开关**——"我能不能让 AI 改一下对我的说法?"
* **当前位置**:能告诉客户"AI 是怎么说你的"
* **下一步**:
  * 自动生成 AI 友好的内容补丁(改 schema / 改 llms.txt / 改实体页 / 建权威信息源)
  * 主动提交至 AI 引擎可索引的渠道,跟踪生效
  * 形成"测量 → 诊断 → 干预 → 复测"的闭环,而不是只到诊断为止
* **战略意义**:从只读工具升级为**执行工具**,客单价上一个量级,从年费数千升至数万级别;同时把客户从一次性使用绑成持续订阅。

### 方向二:从「单品牌」延伸到「行业基准」(数据资产化)

* **产业判断**:谁先掌握"哪个行业里谁被 AI 提得最多",谁就掌握 AI 时代的**行业话语权数据**。这是 SEO 时代 Ahrefs / SimilarWeb 走过的路。
* **当前位置**:每个客户只能看自己的 SAIV
* **下一步**:
  * 把多客户的 SAIV 历史数据匿名聚合,形成**行业 AI 可见性榜单**
  * 榜单本身公开 → 反向获客(品牌看到自己排名靠后会主动找我们)
  * 榜单 + 历史时间序列 → 数据资产化,可独立售卖
* **战略意义**:把"工具公司"升级为"工具 + 数据公司",数据本身就是收入和护城河。

### 方向三:从「工具」延伸到「标准」(争夺裁判位)

* **产业判断**:AI 营销 / GEO 这个赛道目前没有**被行业接受的通用 KPI**。任何一个赛道在早期都会出现一组通用指标,谁定义谁拿走最大份的话语权(SEO 时代的 PageRank / DA / Trust Flow / SERP CTR)。
* **当前位置**:SAIV 是我们的内部指标
* **下一步**:
  * 发布《AI 可见性年度行业报告》,把 SAIV 作为方法论
  * 开源 SAIV 计算口径(部分开源,核心数据闭源)
  * 与媒体 / 行业协会 / 高校合作,把指标推成通用语言
  * 在客户合同 / 提案 / 行业演讲中持续用 SAIV 描述目标
* **战略意义**:护城河从代码升级为**话语权**。一旦行业用 SAIV 说话,我们成为这个赛道的事实裁判,这是远比产品功能更持久的优势。

### 方向四:海外侧 — 从「覆盖引擎」到「嵌入营销技术栈」

* **产业判断**:海外营销技术栈成熟度远高于国内,客户不缺单点工具,缺的是"插得进现有 stack 的新模块"。独立站对海外客户吸引力有限,**嵌入式才有规模**。
* **当前位置**:独立 Web 产品,客户需主动登录使用
* **下一步**:
  * 把核心能力封装为可嵌入第三方平台的模块(HubSpot / Salesforce Marketing Cloud 插件、Chrome 扩展、API for agencies)
  * 覆盖海外特有 AI 入口:Google AI Overviews / Bing Copilot / Perplexity Pages
* **战略意义**:从"再多一个 SaaS"升级为"营销技术栈的标配组件",获客成本与销售周期都会大幅降低。

### 方向五:国内侧 — 从「工具集」到「品牌 AI 应对一体化」

* **产业判断**:国内品牌对舆情和品牌应对的需求远比海外品牌强烈和成熟,但**目前没有一家厂商把"舆情发现 → AI 可见性诊断 → 干预执行"打通**。这是国内独有的机会窗。
* **当前位置**:体检、可见性、舆情三条线技术上已就位,但产品入口分散
* **下一步**:
  * 国内主推**"AI 时代品牌一体化方案"**这个叙事,而不是分别卖工具
  * 一个事件入口贯穿:舆情发现风险 → AI 可见性定位短板 → 自动生成干预包 → 跟踪闭环
  * 服务目标客户从中小品牌上探到中大型品牌 / 公关公司 / MCN
* **战略意义**:国内市场不靠工具竞争胜出(国内付费 SaaS 价格盘小),靠**整体方案**和**响应速度**胜出。

---

## 结语

* **进展回答的是**:"过去这段时间,公司在 AI 产业里站到了哪一层"——产品矩阵成型、双轨能力建立、SAIV 行业语言落地。
* **难点回答的是**:"为了站到这一层,做了哪些不能事后补救的判断"——这是顾问职能区别于执行职能的核心证据。
* **产品方向回答的是**:"接下来怎么继续往上走"——从度量到干预,从单品牌到行业基准,从工具到标准。

如果用一句话概括过去这段周期的核心贡献,是:**把公司从"AI 时代的 SEO 工具"重新定位成"AI 时代品牌可见性的度量与干预层",并把这件事推进到了具备产品矩阵、具备行业语言、具备双轨能力的阶段。**

下一阶段的目标是把这个位置从"具备能力"推进到"占据位置"——从能做,到被市场默认为做这件事的人。
