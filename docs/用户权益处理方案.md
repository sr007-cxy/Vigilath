# 用户权益处理方案

> 本文档定义 GEO Checker 各类用户(匿名 / 注册 / 付费)的**权益边界与执行点**。是工程、运营、客服的统一依据,所有配额和 gate 逻辑都以本文档为准,代码实现只是落地。
>
> 面向用户的套餐营销文案见 `docs/会员功能免费与付费功能项目列表.md`,本文档不重复。

版本:2026-04-17
维护人:后端/产品

## 1. 用户分层

系统里按**认证状态 × 订阅档位**共识别 6 类用户。前 2 类共享"免费检测"路径,后 4 类走"会员"路径。

| # | 用户类型 | slug | 是否需登录 | 标识 | 数据持久化 |
|---|---|---|---|---|---|
| 0 | 匿名访客 | `anonymous` | ❌ 否 | `geo_anon_id` cookie(UUID4) | Redis 缓存 24h;无历史记录 |
| 1 | 注册免费 | `free` | ✅ 是 | JWT → `user_id` | Redis + SQLite 永久历史 |
| 2 | 检测会员 | `pro` | ✅ 是 | JWT | 同上 |
| 3 | Starter | `starter` | ✅ 是 | JWT | 同上 |
| 4 | Growth | `growth` | ✅ 是 | JWT | 同上 |
| 5 | Scale(人工服务) | `scale` | ✅ 是 | JWT | 同上 |

`TIER_RANK` 排序(`backend/geo/models/advanced.py:281`):
```
free=0 < pro=1 < starter=2 < growth=3 < scale=4
```

## 3. 配额规则

### 3.1 匿名用户 —— **不限次数**(2026-04-17 决策)

- `/check/anonymous` / `/geo`(legacy) / 无 token 的 `/check` / 无 token 的 `/geo/stream`:**不强制月配额**
- 后端仍然种 `geo_anon_id` cookie(用于观测、日志、未来反滥用),但不写 `anonymous_check_usage` 表
- **理由**:免费的 5 项展示本身是转化漏斗入口,限 3 次/月把漏斗提前掐死,ROI 为负。单次成本也极低(纯 HTTP 抓取 + 公开 API,无 AI 调用)
- **反滥用**:靠 nginx 层 IP 限流 + anon_id 级日志观测兜底。出现刷量时再上应用层限流,不要默认预设配额

> **历史背景**:2026-04-17 之前匿名每月限 3 次,触发 429 + "Anonymous monthly quota exceeded"。本次改动移除该限制。

### 3.2 注册用户 —— **月配额(tier 决定)**

| tier | `monthly_check_quota` | 月度上限 |
|---|---|---|
| `free` | 3 | 3 次/月 |
| `pro` | 20 | 20 次/月 |
| `starter` | 0 | **无限** |
| `growth` | 0 | **无限** |
| `scale` | 0 | **无限** |

- `quota == 0` 是**无限**的哨兵值(`backend/geo/services/quota_service.py:60`)
- 计量对象只有默认检测(`/check`)。Advanced 端点不计入
- 月窗口:UTC 日历月,key 是 `YYYY-MM`,见 `UserCheckUsageORM`
- 超额时后端抛 `AppException(429, "Monthly check quota exceeded (X/Y). Upgrade to continue.")`
- 前端捕获 429 → 展示 `TierModal` 升级提示(`frontend/src/pages/Result.tsx`)

### 3.3 缓存命中不计数

Redis 命中时直接返回,**不调用** `check_and_increment_quota`。同一 URL 24 小时内重复检测不消耗配额。这是有意为之:同站复查是正常使用场景,不应扣次数。

## 5. 失败态 / 错误码

| 场景 | 状态码 | 用户侧表现 |
|---|---|---|
| 注册/登录表单错误 | 400 / 401 | 表单红色提示 |
| JWT 过期或无效 | 401 / 403 | `useMembership` 检测到,触发 `clearAuth()` 自动登出 |
| 月配额用尽(pro 用户) | 429 | `Result.tsx` 展示 quotaExceeded 条 + 升级 CTA → 打开 `TierModal` |
| advanced mode tier 不足 | 402 | `Advanced.tsx` 展示 `PaymentModal` |
| 外部 AI API Key 缺失 | 503 | "服务暂不可用" 提示 |
| URL 格式非法 | 400 | 表单红色提示 |

## 6. 升级路径

**从匿名进入漏斗的标准流程**:
1. 匿名访客在首页输入 URL → `/check/anonymous` → 看到 5 项结果(18 项 locked 占位)
2. 点击任一 locked 卡片 → 弹 `TierModal`,引导注册或直接买 pro
3. 注册完成 → token 写入 AuthContext → 同一个站再检一次 → `/check` + 完整 25 项
4. free 用户 3 次用完 → 429 → `TierModal` 弹出升级到 pro/starter

**Tier 之间的升级**:走 Stripe `/api/checkout/create`(pro/starter/growth),Scale 走联系销售表单(`/api/contact/sales`)。

## 8. 未决 / 待评估

- **匿名 IP 限流**:目前只种 cookie 不限次。若出现脚本化刷量,需在 nginx 层加 IP 级 token bucket,或应用层对 `anon_id + IP` 做滑动窗口。先观察 `requests.jsonl` 日志,有信号再动手
- **pro 档年付**:当前只有月订阅,年付折扣还没落地
- **组织/团队账户**:多人共享配额的 schema 还没设计
