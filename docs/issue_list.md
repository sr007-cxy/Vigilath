# GEO Checker Issue Register

This file is a historical register of engineering issues and acceptance notes. The current code, tests, and GitHub issues are authoritative for active work.

## Recording an issue

Include severity, affected route or module, reproduction steps, expected behavior, observed behavior, mitigation, and a verification reference. Mark items resolved only after an automated test or reproducible verification exists.

## Priority guidance

- **P0**: security, data loss, or complete service outage.
- **P1**: major user-facing failure, unreliable billing, or unsafe default.
- **P2**: degraded workflow with a documented workaround.
- **P3**: polish, refactoring, or documentation improvement.

Keep historical context concise and link to the maintained architecture, deployment, or performance guide instead of duplicating implementation plans.
