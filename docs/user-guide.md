# GEO Readiness Checker - 用户指南

## 什么是 GEO？

GEO（Generative Engine Optimization）是一种优化网站内容的实践，使其在 AI 驱动的搜索引擎和助手（如 ChatGPT、Google AI Overviews、Perplexity、Copilot 等）中表现更好。

## 如何使用 GEO Readiness Checker

### 1. 访问网站

打开浏览器并访问 GEO Readiness Checker 网站。

### 2. 输入网址

在首页的输入框中输入您想要测试的网站 URL。确保 URL 格式正确，例如：`https://example.com`。

### 3. 运行测试

点击 "Check GEO Readiness" 按钮开始测试。测试过程可能需要几秒钟到几十秒钟的时间，具体取决于网站的大小和响应速度。

### 4. 查看结果

测试完成后，您将被重定向到结果页面，该页面显示：

- **AI Visibility Score**：您的网站的 GEO 就绪度评分（0-100）和等级（A+ 到 F）
- **测试摘要**：通过、警告、失败和信息性检查的数量
- **详细结果**：按类别组织的所有检查结果，包括状态和改进建议

### 5. 获取优化帮助

如果您需要专业的 GEO 优化帮助，可以点击 "Get Optimization Help" 按钮或导航到联系页面，填写联系表单与我们的专家取得联系。

## 测试结果解释

### 状态含义

- **PASS**（绿色）：良好，符合 GEO 标准
- **WARN**（黄色）：可以改进
- **FAIL**（红色）：缺失或损坏，需要注意
- **INFO**（蓝色）：信息性，可选改进

### 评分系统

- **A+**：90-100 分 - 优秀
- **A**：80-89 分 - 良好
- **B**：70-79 分 - 中等
- **C**：60-69 分 - 一般
- **D**：50-59 分 - 较差
- **F**：0-49 分 - 差

## 优化建议

测试结果页面会为每个检查项提供具体的改进建议，特别是对于 WARN 和 FAIL 状态的项目。这些建议旨在帮助您提高网站的 GEO 就绪度。

## 常见问题

### 测试需要多长时间？

测试通常需要 5-30 秒，具体取决于网站的大小和响应速度。

### 测试会影响我的网站吗？

不会，测试只是读取网站的内容，不会对网站造成任何影响。

### 为什么我的网站得分较低？

得分低可能是由于多种因素，如缺少结构化数据、不良的技术爬取性、内容质量问题等。测试结果页面会提供具体的改进建议。

### 我需要多久测试一次？

建议在对网站进行重大更改后测试一次，或者每季度测试一次以确保网站保持良好的 GEO 就绪状态。
