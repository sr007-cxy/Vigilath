# 前端视觉重构方案（方向 A：MoltsPay 深色霓虹赛博）

> **参考站**：[https://moltspay.com/](https://moltspay.com/)  
> **范围**：GEO Checker 前端全栈视觉重构 —— 设计令牌、全局外壳、组件库、11 个页面  
> **不包含**：任何后端业务逻辑、API 接口、数据模型的改动

本方案确认 GEO Checker 前端将**完全套用 MoltsPay 的深色霓虹赛博风格**，包括配色、字体、辉光、漂浮效果、组件间距、Tab 风格、表格样式等全部视觉维度。

---

## 一、已确认的决策

| # | 决策项 | 结论 |
|---|---|---|
| 1 | **技术方案** | 保留 Tailwind；设计令牌全部配进 `tailwind.config.js`；全局效果（网格底、漂浮光斑、滚动条）写在 `index.css` |
| 2 | **主题模式** | 全站**只有深色模式**，删除 `ThemeToggle.tsx` 组件及其所有调用 |
| 3 | **i18n 范围** | 中英双语**同步做视觉适配**（英文字距、中文字重差异都要考虑） |
| 4 | **执行节奏** | 分 **P0 → P1 → P2** 三阶段，每阶段一个独立 PR，便于逐步验证 |
| 5 | **设计系统文档** | 同步新建 `docs/design-system.md`，作为实施后的参考手册（token 命名、辉光规则、组件用法） |
| 6 | **范围约束** | 不改后端、不改业务逻辑、不改 i18n 文案，只改视觉层和样式 |

## 二、待你拍板的 2 件事

### 2.1 字体选型（需要三选一）

| 套系 | Display（大标题） | Body（正文） | 中文 | 调性 |
|---|---|---|---|---|
| **套系 1：硬派赛博** | **Chakra Petch** | IBM Plex Sans | Noto Sans SC | 技术感强，有轻微赛博线条，适合"AI 工具"定位 |
| **套系 2：克制精致** | **Unbounded** | Geist Sans | HarmonyOS Sans SC | 带一点未来感又不过分，企业级定价（¥19.9 起）可信度高 |
| **套系 3：编程感** | **JetBrains Mono**（mono display） | Geist Sans | Noto Sans SC | 完全开发者感，标题也是等宽，最接近 MoltsPay |

> **推荐：套系 1（Chakra Petch）** —— 既有赛博感又不像 Mono 那样抢戏，中文长段落更好读。

**避坑清单**（frontend-design skill 黑名单）：
- ❌ Inter / Roboto / Arial / 系统字体
- ❌ Space Grotesk（skill 点名 "NEVER converge on"）
- ❌ 紫色渐变 + 白底

### 2.2 Motion 强度（需要三选一）

| 选项 | 说明 | 建议 |
|---|---|---|
| (a) 完全照搬 MoltsPay | 多层漂浮 + 全局脉动 + hover 上浮 | 不选 |
| (b) **全效果 + `prefers-reduced-motion` 降级** | 默认完整动效；系统设置开启"减少动效"时自动降级为静态 | ✅ **推荐** |
| (c) 克制版 | 只保留 CTA 呼吸 + hover 上浮 | 不选 |

## 三、设计令牌预设

这些是 P0 阶段要写进 `tailwind.config.js` 的基础值，具体数值可以在实施阶段微调。

### 3.1 颜色系统

```
背景
  bg-base          #0a0a0f                          近黑主色
  bg-elevated      #11111a                          卡片 / 模态底
  bg-overlay       rgba(11, 11, 26, 0.7)            毛玻璃层

霓虹点缀（MoltsPay 四色）
  neon-cyan        #00f0ff                          主强调 + CTA
  neon-purple      #7b61ff                          次强调 + hover
  neon-magenta     #ff006e                          警示 + 降级提示
  neon-green       #00ff9d                          成功 + PASS 状态

文本
  fg-primary       #ffffff                          主标题
  fg-secondary     rgba(255, 255, 255, 0.72)        正文
  fg-muted         rgba(255, 255, 255, 0.48)        辅助说明

边框
  border-subtle    rgba(255, 255, 255, 0.08)        常规边框
  border-glow      rgba(0, 240, 255, 0.4)           辉光边框
```

### 3.2 渐变与辉光

```
gradient-primary   linear-gradient(135deg, #00f0ff 0%, #7b61ff 50%, #ff006e 100%)
gradient-text      同上，作用于 background-clip: text
glow-sm            0 0 20px rgba(0, 240, 255, 0.3)
glow-md            0 0 40px rgba(0, 240, 255, 0.4)
glow-lg            0 0 60px rgba(0, 240, 255, 0.5)
glow-pulse         @keyframes 20px → 60px 3s 循环
```

### 3.3 间距节奏

| token | 桌面端 | 移动端 | 用途 |
|---|---|---|---|
| `section-y` | `6rem` | `3rem` | 大段落垂直 padding |
| `container-max` | `1400px` | — | 顶层容器最大宽度 |
| `gutter` | `2rem` | `1rem` | 水平 padding |
| `stack-lg` | `1.5rem` | `1rem` | 组件堆叠间距（大） |
| `stack-md` | `1rem` | `0.75rem` | 组件堆叠间距（标准） |
| `stack-sm` | `0.5rem` | `0.5rem` | 紧密间距 |

### 3.4 圆角

| token | 值 | 用途 |
|---|---|---|
| `radius-sm` | `0.375rem` | 按钮、小 badge |
| `radius-md` | `0.75rem` | 输入框 |
| `radius-lg` | `1rem` | 卡片 |
| `radius-xl` | `1.5rem` | 模态框 |

### 3.5 动效

```
@keyframes float1..5     不同 easing 的 5-10s 漂浮循环
@keyframes pulse-glow    CTA 呼吸
transition-base          200ms cubic-bezier(0.4, 0, 0.2, 1)
transition-glow          300ms ease-out   hover 辉光过渡
```

## 四、全局外壳（`App.tsx` + `index.css`）

要在 `index.css` 里实现的全局效果：

| 元素 | 实现方式 |
|---|---|
| **固定网格背景** | 60px 间距的 `linear-gradient`，全局盖在所有页面底下（`body::before`） |
| **三个漂浮光斑** | 径向渐变圆 + `filter: blur(120px)` + `float` 动画，作为装饰层（`body::after` 或独立 div） |
| **毛玻璃 Navbar** | `backdrop-filter: blur(20px)` + 顶部 `border-b` |
| **自定义滚动条** | 霓虹细条（`::-webkit-scrollbar`） |
| **自定义 focus ring** | 青色发光边 |
| **选中文字样式** | 青紫渐变（`::selection`） |
| **body 字体引入** | 通过 `@import` 或 `<link>` 加载选定的字体 |

## 五、组件库清单

下表列出**需要全部重做**的组件及重做重点。所有组件都要从白底浅色风格迁移到深色霓虹风格。

| 组件 | 当前状态 | 重做重点 |
|---|---|---|
| **按钮** | Tailwind 默认 | Primary = 青紫渐变 + `pulse-glow`；Secondary = 霓虹边框透明底；Ghost = 仅文字 hover 变色 |
| **输入框 / textarea** | 默认浅底 | 深底 + 底边霓虹线 focus；数字字符用等宽字体 |
| **下拉 select** | 原生 | 自定义组件 + 深底 + 霓虹 hover |
| **单选 / 复选** | 原生 | 自定义方/圆，check 时霓虹填充 |
| **卡片** | 白底圆角 | 深底 + subtle border + hover 上浮 + 角落渐变高光 |
| **Tab** | 不清楚 | 活动态 = 青紫渐变底线 + 文字辉光；非活动态 = 灰文字；切换有平滑过渡 |
| **表格** | 默认 | zebra 用 rgba 透明条纹；表头 = monospace + 青色 + 细边；行 hover = 青色辉光 |
| **Badge / Tag** | 可能没有 | 霓虹描边 pill，角标用 monospace 字号 |
| **Modal / PaymentModal** | 居中卡片 | backdrop blur 20px + 黑色 70% overlay + 卡片 border 辉光 |
| **Toast / Notification** | 可能没有 | 角落飞入，带霓虹左边框 |
| **进度条** | 检测分数 bar | 渐变填充 + 末端辉光点 |
| **状态标签 PASS / WARN / FAIL** | 有 | 霓虹绿 / 霓虹黄 / 霓虹品红，带辉光圆点 |
| **代码块** | 不清楚 | JetBrains Mono + 深底 + 左侧霓虹竖条 |
| **分隔线** | 实线 | 中间有青色发光点的渐变细线 |
| **加载态 skeleton** | 有 | 渐变扫光 |
| **加载态 spinner** | 有 | 青色旋转环 + 辉光 |

## 七、三阶段执行计划

### **Phase 0（第一阶段，1 个 PR）— 基础设施 + 样板页**

1. 改造 `tailwind.config.js`：塞入**全套设计令牌**（颜色 / 字体 / 辉光 / 渐变 / 动效 keyframes / spacing）
2. 改造 `frontend/src/index.css`：写**全局外壳**（网格背景、漂浮光斑、滚动条、focus ring、选中态、body 字体引入）
3. 新建 `docs/design-system.md`：把 token 命名、辉光规则、组件用法全记下来
4. 重做 `Home.tsx` 作为样板页：hero + URL 输入 + CTA
5. 删除 `ThemeToggle.tsx` 组件及其所有调用
6. 本地启动 `npm run dev`，让用户在浏览器先看效果

### **Phase 1（第二阶段，1 个 PR）— 核心营销链路**

1. `ProductsServices.tsx` —— 5 档霓虹定价卡（含 14 项权益对照）
2. `Result.tsx` —— 检测结果页（含 AI Visibility Score 可视化 + 权益对照表）
3. `Navbar.tsx` + `Header.tsx` —— 全站导航
4. `Login.tsx` / `Register.tsx` / `ForgotPassword.tsx` —— 认证三件套
5. `Membership.tsx` —— 精简为会员中心

### **Phase 2（第三阶段，1 个 PR）— 辅助页面**

1. `Landing.tsx` / `About.tsx` / `Contact.tsx` / `GeoKnowledge.tsx`

## 八、风险与注意事项

| 风险 | 说明 | 缓解 |
|---|---|---|
| **Tailwind 保留 vs 抛弃** | MoltsPay 用纯手写 CSS。强行全部改写会伤害 11 个页面的现有 className | 保留 Tailwind，设计令牌塞进 config，某些全局效果用原生 CSS |
| **中文字号偏大** | 霓虹深色背景 + 中文，字号需要比英文大 0.5-1 档，否则看不清 | 在 `tailwind.config.js` 里给中文字体单独定义 `fontSize` scale，或在 `html[lang="zh-CN"]` 下加 base font-size |
| **定价可读性** | ¥19.9 小数字号在辉光下可能糊 | 用 monospace + 加粗 + 高对比，单独处理 |
| **表格深色可读性** | 18 行 × 5 列权益对照表容易糊 | 用透明条纹 zebra + 明确的 row hover 态 |
| **图表重绘** | `Result.tsx` 可视化条形图颜色会和深底融成一片 | 用渐变填充 + 末端辉光点，颜色从霓虹四色中选 |
| **性能** | 多层 blur(120px) 漂浮光斑 + 全局网格 + 动画，低端设备可能卡 | 添加 `will-change` 和 `transform-gpu` 提示；`prefers-reduced-motion` 降级 |
| **i18n 字距** | 英文在赛博字体下字距紧，中文字距宽，同一按钮中英切换可能跳动 | 用 min-width 锁定按钮，或给中英分别设置 letter-spacing |
| **可访问性** | 霓虹色 + 深底对比度可能不达 WCAG AA | 使用 WCAG 检测工具，所有文字至少 4.5:1 对比度 |
