## 二、我方现状：Sentinel 舆情监控系统

### 2.1 架构概览

```
用户配置品牌 → Pipeline 触发
  ├── Monitor（搜索引擎 + 爬虫抓取帖子）
  ├── Analyze（LLM 逐条结构化分析）
  ├── Brief（Map-Reduce 生成日度简报）
  └── Respond（生成三档回应草稿）
```

- **微服务架构**：sentinel-service（FastAPI）独立部署，GEO backend 通过 HTTP RPC 调用
- **多租户隔离**：每个账号独立 SQLite 数据库（`data/account_{id}/yuqing.db`）
- **LLM 多供应商**：支持 GLM（智谱）、Qwen（通义）、DeepSeek、OpenAI 四家，单选模式

### 2.2 数据源能力（持续扩充中）

### 2.3 LLM 分析能力（13 维度）

| 维度 | 字段 | 说明 |
|------|------|------|
| 相关性 | `is_relevant` | 是否与目标个股相关 |
| 情感标签 | `sentiment_label` | bullish / bearish / neutral / mixed |
| 情感分数 | `sentiment_score` | 0~1 浮点数 |
| 情绪 | `emotions` | 愤怒、嘲讽、恐惧、兴奋等 |
| 主题 | `topics` | 业绩、做空、分红、传闻、技术面等 |
| 实体 | `entities` | 人名、机构名、报告名 |
| 立场 | `stance` | supportive / skeptical / neutral / hostile |
| 意图 | `intent` | complaint / praise / rumor / analysis / fud / pump 等 |
| 事实性 | `factuality` | factual_claim / opinion / mixed / unverifiable |
| 风险等级 | `risk_level` | none / low / medium / high |
| 风险信号 | `risk_signals` | [{type, reason}] 结构化风险标签 |
| 影响力 | `influence_potential` | 0~1，综合作者可信度、阅读量、情绪强度 |
| 隐含意 | `hidden_meaning` | 识别反讽、暗语、股吧黑话 |

**亮点**：支持中文股吧黑话识别（韭菜、庄家、拉爆、出货、yyds 等），这是 WisersOne 不一定具备的垂直深度。

### 2.4 简报生成

- **Map-Reduce 架构**：大语料分批处理，最终合并
- **输出结构**：概览 → 关键主题 → 风险信号 → 值得关注的帖子 → 建议动作
- **格式**：Markdown，支持下载/邮件推送

### 2.5 回应草稿生成

- **三档回应**：保守版 / 标准版 / 主动版
- **知识库支持**：品牌语调、法务红线、响应剧本
- **HITL 设计**：所有草稿必须人工审核，不自动发布
- **元数据**：每份草稿附带依据说明、预期效果、注意事项

## 四、差距根因分析

### 根本差异：架构模式不同

```
WisersOne 模式（先存后搜）：
  57 万爬虫 7×24 持续抓取 → 1.8 亿条/天入库 → 用户搜索/监测时从库中匹配
  优势：数据全、响应快、不丢帖
  代价：海量服务器 + 27 年积累 + 大团队运维

Sentinel 模式（先搜后存）：
  用户触发 → LLM 生成搜索计划 → 搜索引擎/爬虫抓取 → 入库 → 分析
  优势：成本低、部署轻、分析深
  代价：依赖搜索引擎可用性、覆盖面窄、实时性差
```

### 数据量少的直接原因

1. **搜索引擎在国内机房不可靠**：DDG 返回空，百度需 Cookie，Bing 刚加
2. **东财股吧是唯一稳定源**：但 VNET 是美股小众票，股吧本身帖子就少
3. **缺少直接爬虫**：雪球、微博、新浪财经等高流量平台没有爬虫模块
4. **只有搜索引擎的"间接抓取"**：无法覆盖搜索引擎未索引的内容

## 六、结论

### 我们不需要成为 WisersOne

WisersOne 是 **通用型媒体监测平台**（57 万源 × 27 年积累），年费通常数万到数十万元。我们的定位是 **金融舆情垂直 AI 工具**，核心竞争力不在数据量，而在：

1. **分析深度**：LLM 13 维度分析 >> 传统 NLP 正负中
2. **回应能力**：三档草稿 + 知识库 + HITL，WisersOne 不提供
3. **成本优势**：自建系统，无需外部订阅
4. **灵活定制**：可按客户需求快速迭代

### 数据量在快速追赶

Phase 1 已完成，数据源从 1 个（东财股吧）扩展到 **7 个爬虫 + 3 个搜索引擎**。
Pipeline 现在每次触发执行：搜索引擎并行（cnbing+百度+DDG）→ 东财股吧(10 页) → 东财资讯(5 页) → 雪球(5 页) → 新浪(3 页) → 百度贴吧(3 页) → 财联社(快讯+搜索)。
预计单关键词日命中量可从 4 条提升至 **50~200 条**（取决于关键词热度和各爬虫可用性），后续解决雪球 WAF 和新浪适配后有望达到 **200~400 条**。

### 差异化竞争策略

```
WisersOne = 广度（57 万源） + 浅度（NLP 三分类）
Sentinel  = 适度广度（10~20 核心源） + 深度（LLM 13 维度 + 回应生成）
```

**我们的目标不是替代 WisersOne，而是在金融舆情这个垂直场景做到"数据够用 + 分析更深 + 回应更快"。**
