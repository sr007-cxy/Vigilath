## 一、现状盘点

### 1.1 已具备的资产

| 层 | 资产 | 成熟度 |
|---|---|---|
| 产品 | 25 类 GEO 检测 + AI Visibility Score(0-100 + 字母等级) | ✅ 成熟 |
| 产品 | 6 档会员阶梯(匿名 $0 → 注册 $0 → Pro $9.99 → Starter $999 → Growth $2,500 → Scale Contact) | ✅ 已落地 |
| 产品 | `--ai-visibility` / `--citation-check` / `--authority-audit` / `--crawl-check` 多模式 | ✅ 成熟 |

| 内容 | CLI + Claude Code skill + README + 多语言 i18n | ✅ 齐备 |

### 1.2 真正影响盈利的断点

流量入口 ≠ 商业化漏斗。现在最大的隐患不是功能缺,而是**转化链路没有外部流量与信任锚点支撑**:

| 断点 | 表现 | 影响 |
|---|---|---|
| A. 冷启动 | 没有自然流量入口,匿名用户从何而来? | 漏斗顶部空转 |
| B. 价格断崖 | Pro $9.99 → Starter $999 直接 **100 倍** | 个人/小团队升不上去 |
| C. 付费钩子不够痛 | 用户拿到低分但没有"具体改哪里"的强制性 | 付费动机弱 |
| D. Scale 销售线索 | $2,500+ 档不会从自助漏斗转化过来 | 高价档无销售素材 |

## 二、核心策略(4 个关键点)

### 2.1 冷启动流量:产品 = 最好的 GEO 案例

**逻辑**:你自己就是目标客户。Vigilath 的目标是帮网站被 AI 引擎引用,那么 `vigilath.com` 本身能否被 ChatGPT / Perplexity 引用,就是最强的产品证明。

**动作**:

1. **公开发布月度 Vigilath 自测分**
   - 每月用 `--ai-visibility` + `--citation-check` 跑自己的站
   - 博客发《Vigilath 如何让自己被 AI 引擎引用 — 2026 年 4 月复盘》
   - 目的:内容营销素材 + 证明工具有效

2. **Competitor vs Vigilath 对比报告**
   - 在博客/GitHub README 里嵌入用 `--compare` 生成的同行对比
   - 目的:用户看到同行被你工具扒得清清楚楚,会主动查自己

3. **把 `llms.txt` / `llms-full.txt` 做到极致**
   - 自己的站必须满分,作为公开的"参考实现"
   - 目的:开发者搜索 `llms.txt example` 能导流到 Vigilath

### 2.2 价格阶梯修复:加中间档 $49/月 Team

**现状**:Pro $9.99 → Starter $999 价差 100 倍,断崖式无法转化。

**建议新增 Team 档**:

| 项目 | 内容 |
|---|---|
| **Slug** | `team` |
| **价格** | **$49/月** |
| **定位** | 独立站长 / 小团队 / 出海个人开发者 |
| **与 Pro 的区别** | 含 Fix 修复建议、无限检测、支持 5 个站点 |
| **与 Starter 的区别** | 无人工服务,无 LLM 收录规范配置,无文案优化 |

**修订后 6 → 7 档**:

```
匿名 $0 → 注册 $0 → Pro $9.99 → Team $49 → Starter $999 → Growth $2,500 → Scale Contact
                                   ↑ 新增
```

**关键点**:Starter 重新定位为 **"含人工服务"** 的增值档(LLM 收录规范配置 + 文案优化),Team 是纯 SaaS 自助档,两者定位不冲突。

**技术实现要点**:

- `backend/geo/services/membership_service.py` 的 `DEFAULT_MEMBERSHIPS` 新增 `team` 条目
- `_FIX_ALLOWED_TIERS` 加入 `team`
- `monthly_check_quota = 0`(无限)
- 新增字段 `max_sites = 5` 约束多站点

### 2.3 付费钩子:锁定"想看答案但看不到"的瞬间

现在匿名 5 项、注册 Free 25 项但无 Fix,Pro 才有优先级排序 —— 设计合理。但**每次拿到低分却看不到"具体改哪里"的那一刻**,才是唯一付费动机。

**动作**:

1. **报告页显式引导**
   - 当检测完成且分数 < B 时,报告底部注入
     > 检测到 **{{n}}** 个可修复问题,升级 Team 查看具体修复步骤
     > 预估分数提升:{{current_grade}} → **{{projected_grade}}**(+{{delta}} 分)
   - 后端能算出 projected score(Fix 全部应用后的满分)
   - 前端在 `frontend/src/pages/Result.tsx` 渲染 upsell 区块

2. **Fix 报告一次性购买 $29/单站**
   - 比月订阅门槛低 30 倍,作为订阅漏斗的前置转化
   - 技术:Stripe one-time payment,后端生成单次解锁 token,7 天内可下载该 URL 的 Fix 报告
   - 转化路径:一次性买 → 体验 Fix 价值 → 后续升级订阅

3. **PDF 报告可下载但带水印**
   - 免费用户可导出带 "Vigilath Free — Upgrade for Priority Order" 水印的 PDF
   - 付费用户导出干净版,可直接给客户/老板
   - 这是 B2B SaaS 标准套路,对独立顾问/外包团队尤其有效

### 2.4 Scale 档销售线索:内容引擎驱动 outbound

$2,500/月 不会从匿名自助转化过来。现在缺两样东西:

1. **公开榜单作 SEO/GEO 内容引擎**
   - 产出"2026 Q2 SaaS 品牌 AI 可见性 TOP 100"
   - 产出"跨境电商 AI 可见性 TOP 50"
   - 产出"医疗 SaaS AI 可见性 TOP 30"
   - 双重价值:
     a. 自己被 Perplexity 引用的可能性最高(榜单类内容)
     b. 上榜品牌会主动联系(免费 PR)
     c. 未上榜的同品类品牌会付费做审计

2. **行业垂直报告(outbound 销售载体)**
   - 按行业产出 3 份《{行业} AI 可见性白皮书》(医疗 / 金融 / 跨境电商)
   - 内含:行业平均分 / TOP 10 品牌复盘 / 典型失分点 / 升级路径
   - 销售外联:发白皮书 + 对方公司的一页纸自测报告 → 直接约 demo

**动作**:

- 每季度产出 1 份榜单 + 1 份行业白皮书
- 榜单直接用 `--ai-visibility` + `--compare` 批量生成,人工润色结论
- 白皮书配套设计模板 + gated download(留邮箱换 PDF)→ 沉淀销售线索

## 五、风险与权衡

| 风险 | 缓解 |
|---|---|
| Team 档蚕食 Starter 客户 | Starter 明确差异化为"含人工服务",Team 只解锁 SaaS 权益 |
| Fix 一次性购买削弱订阅 | 一次性是"体验装",在 Fix 报告末尾强制展示订阅 upsell |
| 榜单产出成本高 | 批量用 `--ai-visibility` 生成,人工只做结论润色,每榜约 1 人日 |
| 自测复盘暴露自己短板 | 正是产品证明 —— 能看到问题并公开改进路径,比完美分数更有说服力 |
