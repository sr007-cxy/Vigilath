# 生成引擎优化（GEO）AI遥测指标体系
**GEO（生成引擎优化）AI遥测**的关键指标体系，覆盖范围远大于传统SEO分析，因为它需要追踪人工智能系统对内容与品牌的全链路行为：
- 发现内容
- 检索信息
- 引用来源
- 内容总结
- 智能推荐
- 通过AI交互界面引导用户转化

一套成熟的GEO遥测框架通常分为**七大层级**：

---

## 一、曝光可见度指标
衡量AI系统能否**抓取、识别并检索**你的品牌与内容。

### 核心指标
| 指标名称 | 指标含义 |
| ---- | ---- |
| AI引用率 | 用户提问提示词中，你的品牌/内容被AI引用的占比 |
| 检索频次 | AI系统调取你网站页面的频率 |
| AI收录页面数 | 进入AI检索链路的网页数量 |
| 提示词覆盖量 | 出现你品牌/内容的提问主题&提示词总数 |
| AI声量份额(SAIV) | AI生态下的品牌声量占比（传统声量份额的AI版） |
| AI曝光体量 | AI生成内容中提及、露出的预估曝光量 |
| 知识图谱收录度 | 品牌是否被纳入AI结构化知识源 |
| 实体识别准确率 | AI能否精准识别你的品牌、企业实体信息 |
| AI可发现性评分 | 综合评估内容被AI检索获取的难易度得分 |

---

## 二、检索与排名指标
追踪AI系统对内容的**优先级排序与语义匹配**表现。

### 核心指标
| 指标名称 | 指标含义 |
| ---- | ---- |
| 检索排名 | 内容在AI检索上下文结果中的位次 |
| 首位引用位置 | 是否在AI回答开篇优先被引用 |
| 上下文纳入率 | 被AI纳入回答上下文的检索片段占比 |
| 语义相关性得分 | 向量嵌入计算的内容语义匹配度 |
| 片段检索成功率 | AI能否精准调取匹配的内容片段 |
| RAG检索命中率 | 检索增强生成的有效命中成功率 |
| 向量搜索召回率 | AI检索内容的完整覆盖度 |
| 嵌入匹配质量 | 内容与用户提问的语义贴合评分 |
| 结构化数据利用率 | AI对网页结构化标记、元数据的调用程度 |
| AI摘要选中率 | 内容被AI选中生成总结摘要的频次 |

---

## 三、内容应答质量指标
衡量AI对**品牌形象、内容信息**的转述与呈现质量。

### 核心指标
| 指标名称 | 指标含义 |
| ---- | ---- |
| 引用准确率 | AI引用信息的准确无误程度 |
| 幻觉错误率 | AI编造、错误描述品牌相关信息的比例 |
| 情感倾向得分 | AI表述中正面/中性/负面的语气倾向 |
| 品牌提及精准度 | AI对品牌名称、定位的表述准确性 |
| 信息传达一致性 | AI表述与品牌官方核心信息的契合度 |
| 事实留存率 | 原有事实信息被AI完整保留的占比 |
| 应答完整度 | AI对你品牌、业务信息的解释全面性 |
| 竞品替代率 | AI用竞品信息替换你品牌提及的概率 |
| AI答案优选率 | 你的内容被AI选为推荐标准答案的频次 |

---

## 四、互动与转化指标
衡量AI生态带来的**下游业务实际价值**。

### 核心指标
| 指标名称 | 指标含义 |
| ---- | ---- |
| AI引流访问量 | 从AI工具跳转至官网的访客数 |
| AI点击率 | AI交互界面内容的用户点击转化率 |
| AI访客会话质量 | AI引流用户的跳出率、浏览深度等会话表现 |
| AI渠道转化率 | AI来源访客产生线索、成交的比例 |
| AI赋能营收 | 由AI发现、种草带动的业务营收 |
| 提示词到访问率 | 经AI曝光后用户跳转网站的比例 |
| 提示词到线索率 | 经AI曝光后产生潜在客户线索的比例 |
| AI访客停留时长 | AI引流用户的网站平均停留时间 |
| AI用户留存率 | AI渠道回访复访的用户占比 |
| AI业务链路贡献度 | AI生态对销售转化链路的营收贡献 |

---

## 五、智能自主代理指标
面向未来AI智能体、自动化工作流的核心指标。

### 核心指标
| 指标名称 | 指标含义 |
| ---- | ---- |
| 智能体调用率 | AI智能体调用你的接口、工具服务的频次 |
| 工具选用率 | 你的工具/服务被AI智能体选中的频率 |
| 自主任务完成率 | AI依托你的系统完成全流程自动化任务比例 |
| 智能体交易体量 | AI智能体发起的订单、支付交易规模 |
| MCP协议兼容得分 | 与AI通信协议、生态标准的适配程度 |
| 智能体接口成功率 | 面向AI智能体的接口调用稳定性 |
| AI智能体留存率 | AI智能体重复调用你服务的频率 |
| 智能体工作流时延 | AI智能体请求服务的响应速度 |
| AI电商成交率 | 由AI主动发起下单的交易转化率 |
| 跨智能体推荐频次 | 多个AI智能体之间互相推荐你品牌的频率 |

---

## 六、GEO技术底层指标
基础设施层面的可观测性运维指标。

### 核心指标
| 指标名称 | 指标含义 |
| ---- | ---- |
| 大模型爬虫访问频次 | AI爬虫、大模型抓取网站的活跃度 |
| AI爬虫覆盖范围 | 访问站点的各类AI机器人类型 |
| 爬虫协议合规度 | AI爬虫是否遵循robots.txt权限规则 |
| 令牌消耗用量 | AI解析、处理你的内容所消耗的Token量 |
| 检索响应时延 | AI调取内容的检索响应耗时 |
| 向量数据库查询时延 | 向量嵌入检索的接口响应速度 |
| 内容新鲜度滞后时长 | 网站内容更新后，AI同步收录的间隔时间 |
| 缓存留存时长 | AI缓存你网站内容的保存周期 |
| 智能体接口可用性 | 面向AI服务的接口在线率、稳定性 |
| 结构化数据源健康度 | 网页结构化标记、信息源的完整合规性 |

---

## 七、竞品对标GEO指标
衡量品牌在AI生态中的**行业竞争站位**。

### 核心指标
| 指标名称 | 指标含义 |
| ---- | ---- |
| 品类AI声量占比 | 品牌在行业品类相关AI提问中的曝光占比 |
| 竞品引用份额差 | 你与竞品在AI引用频次中的相对占比 |
| AI偏好排名 | AI对本品牌及竞品的优先推荐排序 |
| 推荐胜出率 | AI在对比提问中优先推荐你品牌的概率 |
| 品牌权威度评分 | AI算法判定的品牌行业权威分值 |
| 话题语义主导度 | 在行业语义主题集群中的话语权与统治力 |
| 跨模型表现一致性 | 品牌在GPT、克劳德、 Gemini等多AI模型中的表现稳定性 |
| GEO曝光差距 | 与头部竞品在AI生态曝光、引用上的差距值 |

# 落地核心十大关键指标
若搭建实用的GEO遥测数据看板，优先关注这10项：
1. AI引用率
2. AI声量份额
3. AI引流访问量
4. AI渠道转化率
5. 检索排名
6. 引用准确率
7. AI幻觉错误率
8. 提示词覆盖量
9. 竞品引用份额差
10. 大模型爬虫访问频次

# GEO遥测未来趋势
行业正迈向：
**“AI媒介式内容发现的全链路可观测”**

核心内涵：
不再只局限于谷歌等搜索引擎排名，
而是深度洞察AI系统如何认知你的品牌、
如何检索你的数据、
以及如何依托自主智能体做出决策推荐。

随着**AI浏览器、AI购物智能体、AI办公助手、MCP生态体系**持续壮大，这套指标体系的价值会愈发关键。
