# AI Telemetry KPI Framework

AI telemetry measures whether engines discover, retrieve, cite, summarize, and recommend a brand's content.

## Core KPI groups

- **Discovery**: crawl coverage, indexed URLs, and retrieval success.
- **Visibility**: mention rate, rank, share of voice, and query coverage.
- **Citation**: citation frequency, source quality, and linked-page coverage.
- **Sentiment**: positive, neutral, and negative mention ratios.
- **Conversion**: qualified visits, leads, and downstream outcomes.

Every KPI must define its source, aggregation window, denominator, account scope, and failure behavior. Store raw observations separately from derived aggregates so metrics can be recomputed.
