## 一、问题诊断

全站存在**主副定位不一致**:

| 层 | 当前定位 | 典型文案 |
|---|---|---|
| 元数据层(`index.html` title / OG / JSON-LD / `#seo-skeleton`) | ✅ **平台** | `Vigilath — Unified GEO+AEO for Global AI Visibility` |
| 页面层(Hero h1 / CTA / Result 附录 / 法律页) | ❌ **工具** | `GEO Readiness Checker` / `GEO Checker` |

后果:
- 搜索引擎/AI 爬虫抓到的是"平台",但**真人用户打开首页看到的是"检测工具"** —— 与真实商业模式(Free/Pro/Starter/Growth/Scale 五档会员,含托管优化和 PR 支持)严重割裂
- 高价付费档位(Starter $999/mo、Growth $2,500/mo、Scale Demo)难以承接 —— 用户对"一个检测工具"不会产生这种预算认知
- 品牌名 `Vigilath` 未被页面文案强化,用户记住的是"GEO Checker"

## 五、推荐:方案 A

**理由**:

1. **与现有 `<title>` 拉齐** —— `index.html:9` 已是 "Vigilath — Unified GEO+AEO for Global AI Visibility",A 方案的 Hero "Vigilath AI Visibility Platform" 几乎是其缩写,真人用户和 AI 爬虫看到的是同一个品牌故事
2. **付费漏斗自然衔接** —— 副标题的 "audit → fix → grow" 与会员体系(Pro 审计 → Starter 托管修复 → Growth 增长营销)一一对应,用户读完副标题就在潜意识里接受了"需要付费方案"这件事
3. **品牌名强化** —— 报告 footer 从"GEO Checker"改成"Vigilath",用户下载 PDF 传播出去时扩散的是品牌,不是品类
4. **改动风险低** —— 文案层面的增量修改,不动信息架构,不改路由,不改 API
