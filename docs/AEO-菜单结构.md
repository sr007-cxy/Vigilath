# AEO 菜单结构

> 面向市场同学的产品功能清单。对应 8-stage GEO automation pipeline:
> Seed Prompt → Intent Expansion → Prompt Clustering → Content Generation
> → Media Distribution → AI Crawling/Retrieval → Telemetry Collection → Reinforcement Loop

| 菜单 | 子项 | 描述 |
|---|---|---|
| 配置 | 1. 设置(品牌词 + 别名 + 行业)<br>2. 种子提示词(需审核,**只增不改**)<br>3. 意图扩展泛化 + 提示词归类聚类成几个主题(需审核,**只增不改**) | 第一步:填品牌词 + 别名 + 行业。<br>第二步:甲方提交种子提示词 → 平台审核后固化。**已固化的种子词只能增加新的,不能修改。**<br>第三步:系统 LLM 基于种子扇出 200+ 条问题并自动归簇 → 甲方审核 → 固化。**已固化的 query 只能增加新的,不能修改。** |
| 内容创作 | 1. 按 query / 簇 → 单独起稿<br>2. 适配引擎答题套路(listicle / report / case)<br>3. 品牌口吻模板 | 第一步:按 query / 簇分别起稿。<br>第二步:系统按对应引擎的答题套路(listicle / report / case)生成初稿。<br>第三步:套用客户品牌口吻模板。 |
| 内容投放 | 1. 渠道选择(官网 / PR / 垂域 / 社媒)<br>2. 派稿<br>3. 发布状态(待发 / 已发 / URL / 失败) | 第一步:内容进入投放队列。<br>第二步:从渠道库选投放点(官网 / PR / 垂域 / 社媒)。<br>第三步:一键派稿。<br>第四步:跟踪发布状态(待发 / 已发 / URL / 失败)。 |
| AI 检测 | 1. 概览(可见度 / 引用数 / SAIV / 命中位置)<br>2. 引用追踪(query × engine 矩阵)<br>3. 检测详情(每次跑批的答复全文 + citations) | 第一步:每天 02:05 系统自动向 5 个国内 AI 引擎发问。<br>第二步:记录每个引擎的答复 + citations,写入数据库。<br>第三步:看「概览」KPI 总分(可见度 / 引用数 / SAIV / 命中位置)。<br>第四步:进「引用追踪」用 query × engine 矩阵定位具体哪个 cell 命中 / 没中。<br>第五步:在「检测详情」钻进单条答复看原文 + 被引用的网页。 |
| 优化建议 | 1. 优化建议 | 每周一早上 09:00 系统自动出诊断:本周哪些 cell 命中、哪些被竞品挤掉、为什么没中、下周 3-5 条 P0/P1 行动清单(写什么 / 投哪里 / 优先级)。直接展示给客户。 |
