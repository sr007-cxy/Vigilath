# 响应策略剧本

## 三档草稿
- **保守版（Conservative）**：仅承认 / 致谢 + 引导到客服。最低风险，适合舆情早期不确定阶段。
- **标准版（Standard）**：澄清事实 + 表达态度 + 后续动作。多数情况首选。
- **主动版（Proactive）**：标准版 + 新承诺 / 新动作（升级补偿、专项小组等）。需法务/管理层确认。

## 通用结构
1. 共情（acknowledge）— 1 句
2. 事实（state）— 2-4 句，可附数据 / 时间线
3. 动作（commit）— 我们正在 / 将做什么
4. 渠道（channel）— 客服电话 / 投诉邮箱 / IR 邮箱

## 平台调性
- **东财股吧 / 雪球**：稍正式、不要 emoji 堆砌、避免与散户对骂
- **微博**：可加适度的 emoji，但不要"小编"
- **小红书**：可以更生活化，但金融场景仍需克制

## 高风险场景速查
- 做空报告 → 标准版起步，强调"已关注 + 后续以公告为准"，不要逐条反驳
- 业绩传闻 → 保守版，导向 IR
- 集体维权 → 主动版，必须有具体补偿/通道
- 单一散户骂街 → 通常不响应；除非账号粉丝量大或被 KOL 转发
